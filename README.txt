Alasan Pemilihan 5 Data Tambahan (Nilai: 35, 70, 71, 0, 100):

35: Untuk menguji batas bawah kategori NORMAL (tepat saat batas kondisi normal dimulai).

70: Untuk menguji batas atas kategori NORMAL (tepat saat kondisi normal akan berakhir sebelum masuk kategori BASAH).

71: Untuk menguji transisi batas bawah saat masuk ke kategori BASAH.

0: Untuk menguji variasi nilai ekstrem paling bawah (kondisi tanah sangat kering, 0%).

100: Untuk menguji variasi nilai ekstrem paling atas (kondisi tanah sangat basah, 100%).
